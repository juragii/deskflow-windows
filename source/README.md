# DeskFlow — Windows 캘린더 + To do

## 로그인 연결 수정본 (1.1)

브라우저의 빈 사전 연결이 실제 인증 응답 처리를 막을 수 있는 문제를 수정했습니다. 여러 연결을 각각 처리하고, 여러 패킷으로 나뉘어 들어오는 HTTP 요청도 모두 읽습니다. 로그인 대기 시간은 5분입니다. 인증 응답 수신·토큰 교환·연결 완료 단계를 설정에 표시합니다.

기존 프로그램을 종료하고 이 버전의 실행 파일과 config를 사용합니다. 기존 인증 파일 설정, 할 일과 창 설정은 기존 데이터 폴더에서 계속 사용합니다.

로그인 후 브라우저가 `127.0.0.1`로 이동하는 것은 정상적인 로컬 인증 흐름입니다. 해당 페이지에서 연결 거부 또는 대기 화면이 계속 나타나면, **로그인을 시작한 상태에서 5분 안에** 현재 브라우저 주소 전체를 앱 설정의 입력란에 붙여 넣고 **인증 응답 전달**을 누릅니다. 이 주소는 인증 코드를 포함하므로 채팅이나 다른 사람에게 보내지 않습니다. 이전 로그인 시도의 주소는 사용할 수 없습니다.

문제가 계속되면 설정의 ‘데이터 폴더 열기 / 백업’에서 `auth-log.txt`를 확인할 수 있습니다. 로그는 진행 단계와 예외 유형만 기록하며 인증 코드·전체 주소·토큰은 기록하지 않습니다. Google 인증 정보가 필요한 실제 로그인은 배포 전 검증에 포함되지 않았습니다. 수정본 검증 환경에서는 실제 로컬 TCP 접속이 제한되어 HTTP 스트림 처리·수동 전달·입력 검증과 화면을 검증했습니다.

## 실행

ZIP을 원하는 폴더에 압축 해제하고 **DeskFlow.exe**를 실행합니다. Windows 10/11, .NET Framework 4.8 환경용이며 Python, Node.js, 별도 서버는 필요하지 않습니다. 실행 파일과 `DeskFlow.exe.config`를 함께 보관합니다. 소스에서 빌드한 서명되지 않은 개인용 앱입니다.

## 기능

- 월간 달력과 날짜별 Google 일정, 일정이 있는 날짜에 점 표시
- Google 웹에서 표시하도록 선택한 캘린더와 기본 캘린더 조회
- 반복 일정, 종일 일정, 여러 날에 걸친 일정 표시
- 5분 간격 갱신 및 수동 동기화, 통신 오류 시 마지막 일정 유지
- 할 일 추가·수정·삭제·완료 처리, 선택 마감일, 기한 초과 표시, 완료 항목 숨기기
- 테두리 없는 작은 창, 이동·크기 변경, 항상 위 표시, 불투명도 조절
- 트레이 숨기기와 다시 열기, 선택 가능한 Windows 로그인 시 자동 실행

제목 부분을 드래그해서 창을 이동하고, 가장자리로 크기를 조절합니다. **고정**은 다른 창 위에 항상 표시하는 기능입니다. **―**는 트레이로 숨기기, **×**는 종료입니다. 숨긴 뒤에는 Windows 알림 영역의 DeskFlow 아이콘을 두 번 클릭합니다.

이 프로그램은 독립적인 위젯 형태의 창입니다. Windows 바탕화면 배경에 결합되는 셸 위젯은 아니므로 ‘바탕화면 보기(Win+D)’를 누르면 다른 창과 함께 숨겨질 수 있습니다.

## Google 캘린더 최초 연결

Google 계정 암호를 프로그램에 입력하지 않습니다. 기본 브라우저의 Google 로그인 화면을 사용합니다.

1. [Google Cloud](https://console.cloud.google.com/)에서 프로젝트를 선택하거나 생성합니다.
2. [Google Calendar API](https://console.cloud.google.com/apis/library/calendar-json.googleapis.com)를 활성화합니다.
3. Google Auth Platform에서 앱 이름과 지원 이메일을 설정합니다. 개인 Gmail 계정은 대상 사용자를 외부로 설정합니다. 게시 상태가 테스트라면 **대상 → 테스트 사용자**에 로그인할 본인 계정 이메일을 추가합니다.
4. **클라이언트 → 클라이언트 만들기 → 데스크톱 앱**을 선택하고 생성한 클라이언트의 JSON 파일을 다운로드합니다. 웹 애플리케이션 유형은 사용할 수 없습니다.
5. DeskFlow의 **⚙ → 인증 JSON 불러오기**에서 해당 파일을 선택합니다.
6. **Google 로그인 / 다시 연결**을 누르고 브라우저에서 본인 계정의 캘린더 읽기 권한을 승인합니다. 완료되면 프로그램으로 돌아옵니다. 로그인 대기 시간은 5분이며 설정에서 취소할 수 있습니다.

인증 토큰은 Windows 사용자 계정에 종속된 DPAPI로 암호화하여 저장합니다. OAuth 코드 흐름에는 PKCE와 임의 state, 로컬 루프백 콜백을 사용합니다. Google Cloud에서 발급하는 데스크톱 앱 클라이언트 정보가 필요하므로, 인증 파일이 포함되어 있지 않은 배포본은 최초 연결 설정이 필요합니다.

일정은 **읽기 전용**입니다. 일정 항목을 클릭하면 Google 캘린더 웹에서 해당 일정을 열 수 있습니다. 앱에서 일정 생성·변경을 수행하지 않습니다. **To do는 이 PC 전용**이며 Google Tasks나 다른 PC와 동기화되지 않습니다.

캘린더 선택은 Google 캘린더 웹의 표시 체크 상태를 따릅니다. 변경한 후 앱에서 동기화를 누릅니다. 날짜와 시간은 Windows에 설정된 현지 시간대로 표시합니다.

## 문제 해결

- **access_denied / 403**: 현재 로그인한 계정이 테스트 사용자에 등록되어 있는지, Calendar API가 활성화되어 있는지 확인합니다. 조직 계정은 관리자의 앱 제한이 적용될 수 있습니다.
- **invalid_grant / 인증 만료**: Google 로그인 / 다시 연결을 실행합니다. 외부 앱 테스트 상태에서는 승인 유효기간 때문에 재연결이 필요할 수 있습니다.
- **로그인 취소 / 시간 초과**: 앱에서 다시 연결합니다. 브라우저에서 로그인한 뒤 화면을 너무 오래 열어 두지 않습니다.
- **일정 없음**: Google 웹의 캘린더 표시 체크, 앱의 선택 날짜, 마지막 동기화 시간을 확인합니다.
- **이미 실행 중**: 알림 영역에 숨겨진 아이콘을 펼쳐 DeskFlow를 두 번 클릭합니다.

## 데이터와 백업

일반 실행 시 `%LOCALAPPDATA%\DeskFlow`에 저장합니다. 설정의 **데이터 폴더 열기 / 백업**으로 접근할 수 있습니다.

- `data.json`: 할 일, 마지막으로 받은 일정, 창 설정, 데스크톱 앱 클라이언트 정보
- `data.json.bak`: 이전 저장본. 원본 파싱이 실패하면 이 백업을 사용합니다.
- `account.bin`: 암호화된 Google 갱신 토큰. 같은 Windows 사용자 계정에서만 복호화됩니다.

앱을 종료한 다음 데이터 폴더를 복사하여 백업합니다. Google 일정 캐시와 할 일 내용은 로컬 JSON에 포함되어 있습니다. 다른 PC에서는 계정을 다시 연결해야 합니다.

**이 PC에서 연결 해제**는 로컬 로그인 정보와 일정 캐시를 지우며 할 일은 유지합니다. Google 계정 자체의 앱 권한까지 철회하려면 [Google 계정 연결 관리](https://myaccount.google.com/connections)에서 직접 해제합니다.

자동 실행을 켠 경우에는 앱을 옮기기 전에 먼저 끄고, 새 위치에서 다시 켭니다. 제거 시 자동 실행을 끈 다음 프로그램 폴더를 삭제합니다. 데이터까지 지우려는 경우에만 별도로 데이터 폴더를 삭제합니다.

## 빌드 및 검증

소스 코드는 `source` 폴더에 포함되어 있습니다. Windows PowerShell에서 `build.ps1`을 실행하면 Windows 기본 .NET Framework C# 컴파일러로 빌드합니다. 관리자 권한이나 NuGet 패키지는 필요하지 않습니다.

- `DeskFlow.exe --self-test`: 임시 검증 폴더에서 저장·복원·백업, DPAPI, 날짜 경계 및 모의 Google API의 토큰 갱신·페이지네이션·반복 일정 쿼리 검증
- `DeskFlow.exe --verify-ui`: 별도 테스트 데이터로 실제 WPF 창과 버튼 처리, 할 일 추가·완료·표시 전환·월 이동을 검증하고 화면을 렌더링합니다.

검증 명령은 실행 파일 옆 `verification` 폴더에 결과를 기록합니다. 실제 Google 계정 로그인과 온라인 일정 조회는 사용자 인증 파일이 필요하여 배포 전 검증에 포함하지 않았습니다.

참고: [Google 데스크톱 앱 OAuth](https://developers.google.com/identity/protocols/oauth2/native-app), [Calendar Events API](https://developers.google.com/workspace/calendar/api/v3/reference/events/list).
