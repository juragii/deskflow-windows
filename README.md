# DeskFlow 2.3.6 — 크기 조절 위젯·자유로운 시간 입력·마감 알림

- 위젯 오른쪽 아래 손잡이를 끌어 창 크기를 바꾸고 저장합니다. 위치 잠금과 별개로 크기를 조절할 수 있습니다. 수동 크기는 새로고침해도 유지되며 맞춤 버튼으로 자동 크기로 돌아갑니다.

- 달력에는 날짜별 일정 제목을 표시하며 마우스를 올리면 전체 일정과 시간을 볼 수 있습니다.
- 일정 시간은 시(0~23)/분(0~59)을 따로 선택하거나 직접 입력합니다. 방향키로 한 단위씩 조절합니다. 14:07처럼 임의의 분을 지원하고 종료 +1시간 자동 설정을 유지합니다.
- 할 일 추가/수정: 마감일·마감 시각·알림 켜기 및 마감 시각/5·10·30·60분 전 선택. 기존 날짜만 지정한 할 일은 시각을 지정하기 전까지 알림이 발생하지 않습니다.
- PC 알림은 Windows 알림 영역을 사용합니다. 설정에서 테스트할 수 있습니다. 방해 금지/Windows 알림 설정에 따라 표시가 제한될 수 있습니다.
- 휴대폰 Telegram 알림 설정: @BotFather에서 /newbot → 만든 봇에 휴대폰으로 /start → DeskFlow 설정의 봇 토큰 입력 → 내 대화 찾기 → 본인 개인 대화 선택 → 연결 저장 → 테스트 알림. 토큰과 대화 ID는 DPAPI 암호화 저장하며 할 일 제목과 마감 시각이 Telegram으로 전송됩니다.
- PC와 DeskFlow가 켜져 있어야 PC/휴대폰 알림을 보냅니다. 종료/절전 중 놓친 마감은 다음 실행/복귀 후 확인합니다. PC 종료 중에도 정시에 알림을 받으려면 별도 서버/클라우드 스케줄러가 필요합니다.
- PC/휴대폰 성공 이력을 따로 저장해 재실행 중복을 막습니다. 휴대폰 실패는 1/2/4/8/15분 간격으로 재시도하고 완료/알림 해제 작업은 제외합니다.
- Kakao 개발자 지원에 따르면 나에게 보내기 API는 푸시 알림이 발생하지 않아 Telegram을 사용합니다: https://devtalk.kakao.com/t/api/145613 . Telegram 공식 안내: https://core.telegram.org/bots/tutorial .
- 검증: WPF 크기 조절 손잡이 이벤트, 크기 저장/수동 유지/맞춤 복귀, 미완료 할 일 17개 모두 창 안에 표시, 자유 분 입력/마감 수정, 모의 알림 중복·재시도·완료 제외·DPAPI·Telegram 개인대화 및 전송 요청/토큰 오류 노출 방지. 실제 PC 및 휴대폰 알림은 사용자의 설정 후 테스트 알림으로 확인해야 합니다. 실제 Google 일정이나 Telegram 대화로 메시지를 보내지 않았습니다.

# DeskFlow 2.3.4 — 반복 일정 삭제 범위·날짜별 일정 표시

- 반복 일정의 일정 삭제를 누르면 이 일정만 삭제 / 반복 일정 전체 삭제를 선택한 후 확인합니다. 기본 선택은 해당 회차만 삭제입니다.
- 전체 삭제는 과거와 앞으로의 모든 회차를 포함합니다. 선택한 회차의 recurringEventId로 원본 반복 일정을 조회하고 원본의 쓰기 권한과 최신 ETag를 확인합니다. Google 삭제 요청은 선택한 대상의 If-Match를 사용하며 캐시에서도 같은 캘린더의 해당 반복 일정만 제거합니다.
- 위젯 달력의 각 날짜 칸에 일정 제목을 최대 두 개 표시합니다. 추가 일정 개수를 표시하며 마우스를 올리면 해당 날짜의 전체 일정 제목과 시간을 볼 수 있습니다. 날짜를 클릭하면 기존 상세 목록도 이용할 수 있습니다.
- 위젯 기본 크기를 560×820으로 넓히고 작업 영역에 맞게 제한합니다. 기존 저장 위치가 화면을 벗어나지 않도록 보정합니다.
- 검증: 실제 WPF 반복 삭제 선택·확인 흐름, 모의 HTTP 요청 대상/ETag 확인, 관련 없는 일정 보존, 선택하지 않은 날짜의 제목 표시 및 전체 일정 툴팁, 화면 렌더링. 실제 Google 계정의 일정 삭제는 수행하지 않았습니다.

네이티브 최소화 명령·숨김 플래그 차단과 의도적 숨김·재표시, Peek 속성 설정은 검증했습니다. 실제 Explorer의 바탕화면 보기 버튼 클릭은 격리된 검증 환경에서 자동화하지 않았으므로 사용자 PC에서 확인이 필요합니다.

이 저장소와 업데이트 파일은 비공개입니다. 앱은 이 저장소의 업데이트 목록을 읽고 검증된 새 버전을 받아옵니다. 다른 사용자에게 저장소 접근 권한을 추가하지 않으면 GitHub의 일반 사용자에게 공개되지 않습니다.

## 최초 설치

`updates/DeskFlow-update.zip`을 다운로드해 원하는 폴더에 전부 압축 해제합니다. 기존 앱은 트레이 아이콘 우클릭 → 종료로 먼저 종료합니다.

다섯 파일을 같은 폴더에 둡니다: `DeskFlow.exe`, `DeskFlow.exe.config`, `DeskFlow.ico`, `DeskFlow.Updater.exe`, `DeskFlow.Updater.exe.config`. `DeskFlow.exe`를 실행합니다. Windows 10/11 및 .NET Framework 4.8용이며 관리자 권한은 필요하지 않습니다.

## 비공개 자동 업데이트 최초 인증

ChatGPT의 GitHub 계정 연결과 프로그램의 업데이트 읽기 인증은 별개입니다. 프로그램이 준학님 PC에서 직접 읽을 수 있도록 처음 한 번만 설정합니다.

1. 프로그램 **설정 → 비공개 자동 업데이트 → 처음 한 번 연결 설정**을 엽니다.
2. 저장소가 `juragii/deskflow-windows`인지 확인합니다.
3. **읽기 전용 토큰 만들기**를 누릅니다. GitHub에서 fine-grained personal access token을 생성합니다.
4. Resource owner는 **juragii**, Repository access는 **Only select repositories**, 선택할 저장소는 **deskflow-windows** 하나입니다.
5. Repository permissions의 **Contents → Read-only**만 지정합니다. Metadata 읽기 권한은 GitHub가 기본으로 포함합니다. 쓰기·관리 권한은 필요하지 않습니다.
6. 토큰을 생성해 프로그램의 가려진 입력란에 붙여 넣고 **인증 정보 암호화 저장**을 누릅니다. 토큰을 채팅이나 저장소에 보내지 않습니다.
7. **비공개 연결 확인 → 지금 업데이트 확인**을 누릅니다.

토큰은 `%LOCALAPPDATA%\DeskFlow\github-update.bin`에 현재 Windows 계정으로 DPAPI 암호화해 저장합니다. 일반 설정 JSON, 업데이트 목록, 배포 ZIP, 교체 작업 계획에는 넣지 않습니다. 토큰이 만료되면 같은 방법으로 새 읽기 토큰을 등록합니다. 이 PC에서 인증을 지워도 GitHub에서 발급한 토큰 자체는 철회되지 않으므로 필요하면 GitHub 토큰 설정에서 폐기합니다.

## 업데이트 동작

앱 실행 시와 6시간 간격으로 확인합니다. GitHub에서 저장소가 실제 Private인지 확인하고, `updates/latest.json`이 가리키는 변경 불가능한 Git blob을 인증해서 읽습니다. 파일의 SHA-256, 실행 파일 버전, ZIP 내부 경로와 크기를 검증한 뒤 설치를 준비합니다.

편집창이 열려 있거나 입력 중인 할 일이 있으면 적용을 미룹니다. 본 화면을 숨기면 별도 도우미가 앱 종료를 기다려 파일을 교체하고 새 앱의 시작을 확인합니다. 교체나 시작에 실패하면 이전 실행 파일을 복구합니다. 실패한 동일 버전은 자동으로 계속 재시도하지 않습니다. 수동 확인으로 재시도할 수 있습니다.

앱은 GitHub API에 GET 요청만 보냅니다. 토큰은 지정한 저장소의 GitHub API에만 보내며, 다운로드가 외부 GitHub 파일 서버로 이동할 때는 전달하지 않습니다. 자동 이동은 직접 검증합니다. 다른 출처·다른 저장소·HTTP 이동을 거부합니다.

## 일정·할 일·위젯

- 본 화면의 **+ 일정 추가**로 제목, 시작·종료, 종일 여부, 장소, 메모를 입력합니다. 기존 일정은 목록에서 클릭해 편집합니다.
- **이 PC에만 저장**은 Google 로그인 없이 사용할 수 있으며 Google과 동기화되지 않습니다.
- Google에 저장하려면 설정에서 Calendar API의 데스크톱 앱 OAuth JSON을 불러오고 일정 쓰기 권한을 승인합니다. 이전 읽기 전용 버전 사용자는 다시 로그인해야 합니다.
- Google 일정 편집은 최신 내용을 먼저 읽고 다른 곳에서 바뀐 내용을 그대로 덮어쓰지 않습니다. 반복 일정은 선택한 회차만 수정합니다. 참석자가 있는 일정은 Google이 변경 알림을 보낼 수 있습니다.
- Google 승인 후 127.0.0.1 화면에서 멈추면 현재 로그인 시도의 주소를 5분 안에 **프로그램 설정에만** 붙여 넣고 인증 응답 전달을 누릅니다.
- 바탕화면 위젯은 일반 앱 뒤에 유지합니다. 보이지 않으면 **설정 → 위젯 화면 안으로 가져오기**를 사용하거나 **다른 창 위에도 표시**를 켜 위치를 확인합니다.
- 위젯 배경 불투명도는 15~100%로 조절합니다. 글자는 선명하게 유지하며, 위치 잠금을 풀어 이동할 수 있습니다.
- 본 화면 ×는 트레이로 숨깁니다. 프로그램 전체 종료는 트레이 메뉴를 사용합니다.

개인 일정·Google 로그인 정보·할 일은 `%LOCALAPPDATA%\DeskFlow`에 저장하며 이 저장소에 올리지 않습니다. 앱 업데이트는 해당 데이터 폴더를 교체하지 않습니다.

## 개발과 비공개 배포

`source/build.ps1`은 앱과 업데이트 도우미를 빌드합니다. `source/package-update.ps1`은 빌드·검증 후 `out/DeskFlow-update.zip`과 `out/latest.json`을 준비합니다. GitHub Actions나 공개 릴리스가 필수인 방식은 아닙니다.

수정한 버전 번호를 올려 빌드하고, 소스·런타임 ZIP·검증 정보가 들어 있는 업데이트 목록을 같은 Git 커밋으로 이 비공개 저장소에 게시합니다. ZIP의 Git blob SHA가 목록과 일치하는지 확인해야 합니다. 게시된 뒤 사용자 PC의 앱이 새 버전을 자동으로 확인합니다. 채팅에서 코드만 수정하고 저장소에 게시하지 않으면 전달되지 않습니다.

`--self-test`는 저장·복원·Google 모의 API·비공개 인증 및 다운로드·교체와 복구를 검증합니다. `--verify-ui`는 달력·위젯·일정 편집·가려진 인증 입력·암호화 저장과 삭제 화면을 검증합니다. 검증용 가짜 토큰만 사용하며 실제 개인 토큰은 테스트에 사용하지 않습니다.
